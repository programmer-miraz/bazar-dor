# BazarDor — Bangladesh Market Price Tracker

**BazarDor** is a web-based platform built to make everyday market price information more accessible to people across Bangladesh. It allows users to explore essential commodities, check their latest available prices, and monitor price fluctuations to better understand changes in the local market.

## Technologies Used

- **Next.js:** Provides the application structure, routing, and optimized page rendering.
- **React.js:** Powers interactive components and reusable UI elements.
- **TypeScript:** Improves code quality through static typing and better development support.
- **Tailwind CSS:** Enables a clean, responsive design for different screen sizes.
- **REST API:** Connects the application with external sources to retrieve product and pricing information.

## Core Features

1. **Market Price Overview:** Browse essential daily-use products and view their most recently available prices.
2. **Price Trend Monitoring:** Check whether product prices have risen or fallen compared with previous records.
3. **Product Category Navigation:** Explore items through organized categories for faster browsing.
4. **Cross-Device Compatibility:** Use the platform comfortably on mobile phones, tablets, laptops, and desktop computers.
5. **Detailed Product Information:** View product names, prices, measurement units, and price variation percentages in one place.
6. **Smarter Shopping Decisions:** Use market price information to compare products and plan everyday purchases more effectively.

## Project Goal

The main objective of BazarDor is to simplify access to market price information and help consumers become more aware of changing commodity prices. By presenting product data in a clear and organized format, the platform aims to make everyday shopping research easier and more convenient.
